# Questie Raven

Addon: `Questie` · Interface **11402** · Version **7.0.1**

## About

Base Questie functionality has been adapted toward **1.18**-level content and **Raven** features (wide IDs, Raven races, zones, and a Lua quest pack).

The folder name must remain **`Questie`**. Do not install stock Questie, `CinderQuestieData`, or legacy `!CinderCompat` beside this fork as a replacement.

## Status — not a final release

This is **not a finished, bug-free product**. Expect gaps in quest data, map pins, and edge cases.

## Bugs / feedback

If you find a problem, open an **Issue** in this repository:

- Questie TOC version and client build;
- quest id / zone / faction;
- steps to reproduce;
- map screenshot or error text.

## Install

Copy `Questie` into `Interface\AddOns`, then `/reload`. The first login after install may recompile the database once (temporary lag).
